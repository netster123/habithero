# HabitHero

Eine kleine Web-App, die beim Rauchstopp, beim Training zu Hause, beim Essen und beim Schlafrhythmus begleitet –
mit Punkten, Leveln und Tagesaufgaben.

**App öffnen:** https://netster123.github.io/habithero/

Auf dem iPhone in Safari öffnen und über **Teilen → Zum Home-Bildschirm** installieren.
Alle Daten bleiben auf dem Gerät.

## Quellen der Nährwerte

- Lebensmittel: USDA FoodData Central, SR Legacy (gemeinfrei)
- Tagesbedarf: D-A-CH-Referenzwerte der Deutschen, Österreichischen und Schweizerischen Gesellschaft für Ernährung
- Übersetzung von Suchbegriffen: MyMemory
